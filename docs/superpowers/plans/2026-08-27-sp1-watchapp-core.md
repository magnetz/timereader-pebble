# TimeReader Pebble SP1 — Watchapp Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Pebble Time (basalt) watchapp that runs in the emulator, showing a hard-coded book list, book detail with stats, a reading timer with pause/resume, page digit entry, an end-of-session menu, a session summary with retract, and crash/quit recovery — with all pure logic covered by host-compiled C tests.

**Architecture:** Pure decision logic (`digit_entry`, `session`, `state_machine`) lives in plain C files with no Pebble headers, compiled and tested on the host with a tiny dependency-free assert harness. PebbleOS-facing code (`main`, `store`, `ui_*`) is thin: it translates button clicks into state-machine events and renders the state-machine's output using native components (`MenuLayer`, `ActionMenu`, `StatusBarLayer`, `ActionBarLayer`, system window transitions). SP2 (companion + BT sync) is a separate plan; this plan seeds books in code and stubs the sync boundary.

**Tech Stack:** C (Pebble SDK 4.x / Rebble fork, `basalt` platform only), `pebble-tool` via `uv`, host C compiler (`cc`) for logic tests, `pebble` emulator for integration checks.

**Spec:** `docs/superpowers/specs/2026-08-27-companion-bt-sync-design.md` (SP2 spec; its "Watchapp: interazione a 4 tasti" and "Aderenza alle linee guida UI ufficiali Pebble" sections are the SP1 contract). Cross-reference the original MicroPython implementation at `../m5/timereader/firmware/app/` (`state_machine.py`, `digit_entry.py`, `session.py`, `completion_estimate.py`) and its spec `../m5/timereader/docs/superpowers/specs/2026-08-25-reading-timer-design.md` for the behaviour being ported.

## Global Constraints

- Target platform: **`basalt` only** (Pebble Time / Time Steel, 144×168, 64 colours). `package.json` `targetPlatforms` = `["basalt"]`.
- App UUID (verbatim): `bfdd20e5-1c38-4c97-85ee-486042b64b96`
- App type: watchapp launched from the launcher, **not** a watchface. `watchapp.watchface` = `false`.
- Python for `pebble-tool`: **3.13** (`pebble-tool` does not support 3.14).
- Back button is always "one step back" — never repurposed for an unrelated action. Window transitions are the **system defaults** (never overridden).
- Native components over custom reimplementations: `MenuLayer` for the book list, `ActionMenu` for the end-session menu, `StatusBarLayer` on the timer/detail/summary windows, `ActionBarLayer` on the timer.
- System fonts only: `FONT_KEY_GOTHIC_28_BOLD` for headline values, `FONT_KEY_GOTHIC_18` for labels (never smaller than 18), `FONT_KEY_BITHAM_42_BOLD` for the timer `mm:ss`.
- Session recovery rule (verbatim from spec): a session persisted as `RUNNING` **always** resumes as `PAUSED`, never auto-running; displayed elapsed time must not advance before an explicit resume.
- Reading-rate rule (verbatim from original spec): average pages/hour is `Σ pages / Σ duration`, **never** the mean of per-session rates.
- Page validation: `end_page >= start_page`; a lower value shows a brief error and does not complete the session.
- All commits use Conventional Commits (`feat:`, `test:`, `chore:`, `fix:`, `docs:`).

A single-header harness. Registration via a static array populated by a `REGISTER_TEST(fn)` macro using a constructor attribute, or simpler: an explicit `RUN(test_fn)` list inside `TEST_MAIN`. Use the explicit-list form:
```c
#define CHECK(cond, msg) do { \
  tests_run++; \
  if (!(cond)) { printf("FAIL: %s (%s:%d) %s\n", #cond, __FILE__, __LINE__, msg); tests_failed++; } \
} while (0)
#define CHECK_EQ_INT(a, e, msg) do { \
  tests_run++; \
  if ((a) != (e)) { printf("FAIL: %s == %s | got %d want %d (%s:%d) %s\n", #a, #e, (int)(a), (int)(e), __FILE__, __LINE__, msg); tests_failed++; } \
} while (0)
/* CHECK_EQ_STR uses strcmp, same shape */
extern int tests_run, tests_failed;
#define TEST_BEGIN() int tests_run = 0, tests_failed = 0; int main(void) {
#define TEST_END() printf("%d passed / %d failed\n", tests_run - tests_failed, tests_failed); return tests_failed ? 1 : 0; }
```

## Task 3: Digit entry logic

Port of `../m5/timereader/firmware/app/digit_entry.py`. A 4-digit buffer with an active-cursor position; Up/Down change the active digit (wrap 0–9), Select confirms and advances, Back retreats one digit, Back on digit 0 signals cancel.

**Files:**
- Create: `watchapp/src/c/digit_entry.c`, `watchapp/src/c/digit_entry.h`
- Test: `tests/c/test_digit_entry.c`

**Interfaces:**
- Consumes: nothing.
- Produces:
  ```c
  typedef struct { int digits[4]; int cursor; } DigitEntry;
  void digit_entry_init(DigitEntry *e, int prefill);      /* prefill 0..9999 -> digits, cursor=0 */
  int  digit_entry_value(const DigitEntry *e);            /* digits -> 0..9999 */
  void digit_entry_up(DigitEntry *e);                     /* active digit +1 mod 10 */
  void digit_entry_down(DigitEntry *e);                   /* active digit -1 mod 10 */
  bool digit_entry_select(DigitEntry *e);                 /* advance cursor; returns true if that was the last digit (entry complete) */
  bool digit_entry_back(DigitEntry *e);                   /* retreat cursor; returns true if cursor was already 0 (caller should cancel) */
  ```

```c
#include "digit_entry.h"

void digit_entry_init(DigitEntry *e, int prefill) {
  if (prefill < 0) prefill = 0;
  if (prefill > 9999) prefill = 9999;
  e->digits[0] = (prefill / 1000) % 10;
  e->digits[1] = (prefill / 100) % 10;
  e->digits[2] = (prefill / 10) % 10;
  e->digits[3] = prefill % 10;
  e->cursor = 0;
}
int digit_entry_value(const DigitEntry *e) {
  return e->digits[0]*1000 + e->digits[1]*100 + e->digits[2]*10 + e->digits[3];
}
void digit_entry_up(DigitEntry *e)   { e->digits[e->cursor] = (e->digits[e->cursor] + 1) % 10; }
void digit_entry_down(DigitEntry *e) { e->digits[e->cursor] = (e->digits[e->cursor] + 9) % 10; }
bool digit_entry_select(DigitEntry *e) {
  if (e->cursor >= 3) return true;
  e->cursor++;
  return false;
}
bool digit_entry_back(DigitEntry *e) {
  if (e->cursor == 0) return true;
  e->cursor--;
  return false;
}
```

```c
#include "session.h"

void live_session_start(LiveSession *s, int start_page, int now) {
  s->start_page = start_page; s->accumulated_seconds = 0; s->segment_start = now;
}
void live_session_pause(LiveSession *s, int now) {
  if (s->segment_start >= 0) { s->accumulated_seconds += now - s->segment_start; s->segment_start = -1; }
}
void live_session_resume(LiveSession *s, int now) {
  if (s->segment_start < 0) s->segment_start = now;
}
int live_session_elapsed(const LiveSession *s, int now) {
  int e = s->accumulated_seconds;
  if (s->segment_start >= 0) e += now - s->segment_start;
  return e;
}
int total_hours_x100(const Session *ss, int n) {
  long secs = 0; for (int i = 0; i < n; i++) secs += ss[i].duration_seconds;
  return (int)((secs * 100) / 3600);
}
int pages_per_hour_x100(const Session *ss, int n) {
  long pages = 0, secs = 0;
  for (int i = 0; i < n; i++) { pages += ss[i].pages; secs += ss[i].duration_seconds; }
  if (secs == 0) return 0;
  return (int)((pages * 3600 * 100) / secs);
}
int current_page_from_sessions(const Session *ss, int n, int book_current_page) {
  return n > 0 ? ss[n - 1].end_page : book_current_page;
}
int pages_left(int total_pages, int current_page) {
  int d = total_pages - current_page; return d > 0 ? d : 0;
}
int eta_minutes(int pl, int pph_x100) {
  if (pph_x100 == 0) return 0;
  return (int)(((long)pl * 60 * 100) / pph_x100);
}
```

## Task 5: State machine

Port of `../m5/timereader/firmware/app/state_machine.py`, adapted to 4 buttons and the SP2-spec interactions (Back-a-digit, `END_SESSION_MENU`, summary retract). This is the heart of the app; keep it a pure function of `(state, context, event) -> (new state, side effects)`.

**Files:**
- Create: `watchapp/src/c/state_machine.c`, `watchapp/src/c/state_machine.h`
- Test: `tests/c/test_state_machine.c`

**Interfaces:**
- Consumes: `model.h`, `digit_entry.h`, `session.h`.
- Produces:
  ```c
  typedef enum {
    FX_NONE, FX_START_SESSION, FX_SAVE_SESSION, FX_DISCARD_SESSION,
    FX_RETRACT_SESSION, FX_PAGE_ERROR, FX_PERSIST_STATE
  } SideEffect;

  typedef struct {
    AppState state;
    int book_index;           /* into the book array; -1 if none */
    int book_count;
    int detail_page;          /* 0..2 */
    int end_menu_index;       /* 0..2 within END_SESSION_MENU */
    bool end_menu_confirming; /* second-confirm for "exit without saving" */
    DigitEntry entry;
    LiveSession live;
    AppState state_before_end_page;   /* RUNNING or PAUSED, to restore on cancel */
    int start_page_for_session;
    int last_session_pages;   /* for the summary screen */
    int last_session_seconds;
  } SmContext;

  /* books[] is read-only context the caller owns (seed for SP1, cache for SP2) */
  void sm_init(SmContext *c, const DigestBook *books, int book_count, int now);
  void sm_restore(SmContext *c, const DigestBook *books, int book_count,
                  AppState persisted_state, int persisted_start_page,
                  int persisted_elapsed_seconds, int now);   /* RUNNING -> PAUSED per spec */
  SideEffect sm_handle(SmContext *c, const DigestBook *books, Event ev, int now);
  ```
  `sm_handle` returns the single side effect the caller must perform (persist, save a session row, etc.). When `FX_SAVE_SESSION` / `FX_RETRACT_SESSION` fire, the caller reads `c->entry`, `c->live`, `c->start_page_for_session`, `c->book_index` to build the row.

- [ ] **Step 2: Complete `ui_dispatch` side-effect handling**

```c
void ui_dispatch(Event ev) {
  int now = (int)time(NULL);
  int n; const DigestBook *b = seed_books(&n);
  SideEffect fx = sm_handle(&g_ctx, b, ev, now);
  switch (fx) {
    case FX_PERSIST_STATE:
      store_save_session(g_ctx.state, g_ctx.start_page_for_session,
                         live_session_elapsed(&g_ctx.live, now));
      break;
    case FX_START_SESSION:
      store_save_session(APP_RUNNING, g_ctx.start_page_for_session, 0);
      break;
    case FX_SAVE_SESSION:
      /* SP1: no session log yet — SP2 adds the queue. Just clear recovery. */
      store_clear_session();
      break;
    case FX_DISCARD_SESSION:
    case FX_RETRACT_SESSION:
      store_clear_session();
      break;
    case FX_PAGE_ERROR:
      ui_digit_flash_error();
      break;
    case FX_NONE: break;
  }
  ui_route_to_state();
  ui_refresh_current();   /* calls the top window's *_refresh */
}
```
